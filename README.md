Instructions
============

This project was initially generated by `eliom-distillery` as the basic
project `project_name`. This version builds the application as a standalone
executable, with the Web server linked in as a library.

Generated files
---------------

The following structure has been generated by eliom-distillery:

 - app/
   This directory contains the main application code.
   *project_name.eliom* registers the Eliom services.

 - app/main/
   This defines a standalone executable that configures and runs the Web server
   and application. It's an alternative to writing a configuration for
   ocsigenserver.

 - project_name.conf
   The ocsigenserver configuration, as an alternative to using the standalone
   executable.
   Feel free to remove whichever of app/main/ or project_name.conf you don't
   use.

 - lib/
   This directory defines an Eliom library as a template for organizing your
   application into local libraries. It is optional.

 - static/
   Put your CSS or additional JavaScript files here.
   Update the copy rule in *dune* to make local runs work.

 - dune
   Dune is the build system for OCaml. This file defines rules for updating
   the local/ directory and for installing the files to be served.

 - dune-project
   This file defines the project's OCaml dependencies. After modifying this
   file, run *dune build* to update project_name.opam.

 - local/
   This directory contains the server state (logs, database, command pipe, and
   the compiled client side code) when running locally. Do not put anything
   here manually.

Running locally (standalone executable)
---

To run your application locally:

    $ dune build
    $ dune exec project_name

The first command updates the generated files in local/ and the second runs
the application.

Running locally (using ocsigenserver)
---

To run your application locally:

    $ dune build
    $ dune exec -- ocsigenserver -c project_name.conf

The first command updates local/ and builds the findlib libraries that
ocsigenserver will look up. The second command spawns ocsigenserver, using Dune
to set up the environment for the local project.
